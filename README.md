# FAE UDP Working Paper Series

Static website for the Working Paper Series of the Facultad de Administración y Economía, Universidad Diego Portales.

## GitHub Pages
Publish from the main branch and repository root in Settings > Pages.

## Included sample assets
- papers/FAE-WP-0-cover-test.pdf: sample PDF cover.
- templates/FAE-WP-0-cover-editable.pptx: editable PowerPoint cover.

The site is structured so final working-paper PDFs can later point to public Dropbox links.
